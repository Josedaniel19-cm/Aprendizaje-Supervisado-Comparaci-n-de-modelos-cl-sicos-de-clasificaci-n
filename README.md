# Aprendizaje-Supervisado-Comparaci-n-de-modelos-cl-sicos-de-clasificaci-n
El trabajo compara tres modelos de aprendizaje supervisado para clasificar diagnósticos benignos y malignos. Incluye limpieza y exploración de datos, estandarización, validación cruzada y evaluación final. Su propósito es identificar el modelo con mejor rendimiento y capacidad de generalización.
